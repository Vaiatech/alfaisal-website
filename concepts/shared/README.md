# Shared assets for the three home-page concepts

- `logo/` — traced vector logo. `alfaisal-logo.svg` (full lockup, groups: pen, calligraphy, scale, penband, wordmark, tagline, rule; viewBox 0 0 1031 1195),
  `alfaisal-mark.svg` (calligraphy + pen + scale only), plus on-dark and white variants. Brand colours: gold #AD832D, light gold #E2BE76, pen gold #BD882C, maroon #8A1C1C, tagline ink #4A1410.
- `calligraphy-strokes.json` — 39 pen strokes traced along the skeleton of the gold calligraphy, in writing order (`d` path in the 1031×1195 logo space, `w` stroke width that covers the letter, `l` length). Use them as a stroke mask to make the calligraphy "write itself".
- `fonts/` — Almarai 400/700/800 (Arabic + Latin, the font of the firm's consultation platform uhearu.com) and Noto Naskh Arabic variable (calligraphic accent). SIL OFL.
- `content.ts` — all approved copy, numbers, contact details and menu (from the client's PDF).
- `photos/` — the only real photos available: three practice-group leaders (Waleed Al-Mutairi, Sahl Al-Garf, Ahmed Al-Zahrani). Mixed quality/backgrounds.
